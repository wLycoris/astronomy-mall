## 项目简介

天文器材商城系统是一个面向天文爱好者的一站式智能化服务平台，将「器材电商」与「AI 识别」「知识学习」「地理位置」「社区内容」「个性化推荐」五个维度打通，形成完整的产品生态闭环：

> 拍星图 → AI 识别星体 → 推荐器材/课程 → 下单购买 → 学习进阶 → 分享交流 → 再次推荐

项目按照真实商业项目的工程标准搭建，前后端分离，覆盖用户端、管理后台、定时任务、异步通知、日志审计等完整能力，历时 16 周独立完成。

## 核心创新点

- AI 星图识别：接入 Astrometry.net API，上传星空照片即可识别天体，并联动推荐器材与课程
- 混合推荐算法：标签 Jaccard 相似度 + 特征向量余弦相似度 + Item-based 协同过滤，冷启动三级兜底
- 地理位置智能联动：接入高德地图 API，观测点推荐 + 天气月相评估 + 签到打卡
- NASA 多 API 对接：APOD 每日天文图首页展示 + 自动同步课程 + 火星车图库
- 完整支付闭环：支付宝 / 微信 / 余额支付，订单-支付-退款全状态机
- 三层日志审计体系：登录日志 + 管理员操作日志 + 商品变更日志（AOP 切面 + 字段级变更追踪）
- "学习 → 识别 → 购买 → 分享"生态闭环

## 项目结构（简览）

```
astronomy-mall/
├── backend/                    # Spring Boot 后端
│   └── src/main/java/com/astronomy/mall/module/
│       ├── user/                # 用户管理
│       ├── product/             # 商品管理
│       ├── cart/                # 购物车
│       ├── order/                # 订单管理
│       ├── payment/              # 支付管理
│       ├── admin/                # 后台管理
│       ├── notification/         # 消息通知中心
│       ├── aftersale/            # 售后服务
│       ├── favorite/             # 商品收藏
│       ├── recognition/          # AI 星图识别
│       ├── nasa/                 # NASA API 集成
│       ├── course/               # 天文课程
│       ├── location/             # 地理位置推荐
│       ├── forum/                # 论坛社区
│       └── recommend/            # 推荐系统
└── frontend/                   # Vue3 前端
    └── src/
        ├── views/                # 63+ 页面
        ├── api/                  # 接口封装
        ├── store/                # Pinia 状态管理
        └── router/               # 路由配置
```

> 项目采用「模块内聚」组织方式：同一业务模块的 entity / mapper / service / controller / dto / vo 统一收纳在同一包下，业务模块之间通过 Helper 类调用（如通知模块 NotificationHelper），避免代码分散。

## 项目亮点

### 技术亮点
- 前后端分离架构（Vue3 + Spring Boot）
- JWT 无状态认证 + 三层拦截器（白名单 / 可选 / 保护）
- 购物车实时同步 + 商品快照机制
- 订单状态机设计（待支付 → 待发货 → 待收货 → 已完成）
- 库存自动管理 + 超卖防护
- 支付 / 退款流程设计（余额支付 + 行锁负值校验）
- AOP 操作日志切面（@AdminLog + @ProductLog，字段级变更追踪）
- 消息通知中心（35 条模板 / 异步发送 / 铃铛角标 / 用户自定义偏好）
- Jaccard + 协同过滤混合推荐算法（标签相似度 × 0.5 + 分类 × 0.3 + 价格 × 0.2，冷启动三级兜底 + Redis 缓存）
- 跨模块异构信号编排：识别→课程 / 完课→下一门 / 签到→器材 / 帖子→帖子，四条推荐联动线
- AI 星图识别（Astrometry.net 接入 + 30 秒轮询调度 + 中英双语天体标签）
- 高德地图集成（观测点地图 + 天气月相评估 + 签到 Haversine 距离校验）
- 论坛社区（小红书风格瀑布流 + 关注/搜索/热度计算 + 9 种通知类型）
- ECharts 数据可视化 + Excel 批量导入导出

### 业务亮点
- 完整购物流程：商品 → 购物车 → 订单 → 支付 → 收货 → 评价 / 退款
- 完整售后体系：安装预约 + 器材保养提醒 + 二手回收
- 完整后台管理：9 大管理模块全覆盖
- 天文课程生态：APOD 每日同步 + 火星探测车课程 + 完课推荐
- 地理位置服务：观测点推荐 + 天气适宜度评估 + 签到打卡

### 创新亮点
1. 垂直领域定位 —— 天文器材 + AI 识别 + 课程 + 社区 + 推荐的生态闭环
2. 跨模块推荐信号编排 —— 浏览 / 收藏 / 购买 / 识别 / 签到 / 帖子等异构数据统一进推荐管道
3. AI 识别 → 商业转化链路 —— 识别星图 → 推荐器材 + 课程 + 发送通知
4. 三层日志审计体系 —— 登录日志 + 管理员操作日志 + 商品变更日志
5. 地理位置与器材推荐联动 —— 观测点高度 / 光污染等级 → 推荐适合器材
